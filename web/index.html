    你可能想問

    同其他「粵語」語音識別有咩唔同？

    好多模型將「粵語」當成一種書面中文嚟處理：出簡體字、將口語改寫做書面語，或者用其他地區嘅口音同用詞訓練。呢套模型專登為香港廣東話調校：出繁體字、保留口語寫法、英文照寫英文，喺香港相關測試集嘅錯字率都低過原版 Qwen3-ASR。

    段聲會唔會上傳？

    唔會。模型下載落你部機，喺瀏覽器入面運行，錄音同檔案都唔會離開你部機。呢個網站唔收集任何數據。

    點解咁慢，載入咗好耐？

    第一次要下載約 1.2 GB。之後會用 cache。冇 WebGPU 嘅瀏覽器會用 CPU（WASM），會慢好多。最好用電腦版 Chrome 或 Edge；想快又準，用桌面版 1.7B 或者 OraType。

    點解唔建議用手機？

    手機瀏覽器可用嘅記憶體同 GPU 有限，載入 1.2 GB 模型好易閃退，就算載到都會好慢同發熱。用電腦試先有代表性嘅體驗。

    可唔可以加自訂詞彙（hotwords）？

    模型支援 hotword context biasing，而且唔會亂寫冇講過嘅詞（parrot rate 0%）。網頁版暫時未開放，可以用 Python 或者 llama-server 試，詳情睇 GitHub。
